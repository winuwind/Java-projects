# Стековый калькулятор

---------------------------

## Описание
Консольное приложение, которое принимает в качестве аргумента командой строки имя файла, содержащего команды. Если аргумента нет, то использует стандартный поток ввода для чтения команд. Использует вещественные числа.

Поддерживается следующий набор команд:
1. `#` - строка с комментарием.
2. `POP`, `PUSH` — снять/положить число со/на стек(а).
3. `+` , `-` , `*` , `/`, `SQRT` – арифметические операции. Используют один или два верхних элемента стека, изымают их из стека, помещая результат назад
4. `PRINT` — печать верхнего элемента стека (без удаления).
5. `DEFINE` — задать значение параметра. В дальнейшем везде использовать вместо параметра это значение.

Реализован набор модульных тестов, покрывающих функционал калькулятора. 

Реализовано журналирование процесса работы калькулятора.

## Особенности
1. Реализован набор модульных тестов, покрывающих функционал калькулятора.
2. Реализовано журналирование процесса работы калькулятора.

## Запуск
    >gradle build
    >./gradlew run --args="<inFile = stdin> <level = WARNING>"
Поддерживаемые уровни логирования:
1. `INFO`
2. `WARNING`
3. `ERROR`
