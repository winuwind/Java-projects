# Анализатор текстовых файлов

----------------------

## Описание
Консольное приложение, читающее текстовый файл и создающее `CSV` файл с колонками:
1. Слово
2. Частота
3. Частота (в %)

CSV файл должен быть упорядочен по убыванию частоты, то есть самые частые слова
должны идти в начале. Разделителями считать все символы кроме букв и цифр.

## Запуск
    >gradle build
    >./gradlew run
Или:

    >gradle build
    >./gradlew run --args="arg1 arg2 arg3 ..."

Аргументами `arg1`, `arg2`, `arg3` и тд. могут быть:

1. `-s typesort` - Указать тип сортировки: `more` для сортировки по возрастанию, `less` для сортировки по убыванию. По умолчанию используется сортировка по возрастанию.
2. `-f typefile` - Указать формат выходного файла: `csv` для `CSV` файла, `html` для `HTML` файла. По умолчанию используется `csv`.
3.  `-i name` - Указать имя входного файла. По умолчанию имя входного файла `in.txt`.
4.  `-o name` - Указать имя выходного файла. По умолчанию имя выходного файла `out`.
