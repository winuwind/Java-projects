# Сапёр

-----------------------

## Описание
Аналог игры «Сапер» (“Minesweeper”) из состава стандартных программ для Windows OS. 

Архитектура программы основана на паттерне MVC (Mode-View-Controller).

Программа имеет два интерфейса – текстовый и графический, причем оба интерфейса должны использовать одну и ту же игровую модель. Т.е. классы  данных и логики одинаковые для текстового и графического интерфейсов.

Графический интерфейс реализован с помощью библиотеки `Swing`.

## Особенности
1. Размер поля и количество мин можно изменить. По умолчанию поле размером 9x9 и
количество мин 10.
2. Игра поддерживает таблицу рекордов.
3. Пользователю доступны команды: Exit, About, New Game, High Scores.
4. Отчет времени реализован отдельным потоком.

## Запуск
Для запуска можно использовать один из скриптов запуска из этой [директории](https://github.com/winuwind/Java-projects/tree/main/Minesweeper/Minesweeper).

Вы можете запустить иначе:
    
    >gradle build
    >./gradlew run --args="<-r records> <-t>"

1. `-r records` - Используется для указания имени файла с таблицей рекордов. По умолчанию `Records.msr`.
2. `-t` - Используется для запуска программы в текстовом режиме.

## Текстовый режим
В текстовом режиме пользователю доступны следующие команды:
1. `New Game` - Начать новую игру.
2. `Open` - Открыть клетку.
3. `Note` - Отметить клетку.
4. `Restart` - Начать новую игру с теми же настройками.
